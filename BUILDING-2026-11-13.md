## Historical environment and reproducibility limits
The source release preserves the actual source revisions, cache, recipes, dependency source changes/patches, target toolchain configuration and upstream build instructions. The complete historical container digests, OS-package versions and compiler/linker versions were not recovered. Upstream image names and package installation are not immutable.

Record those details and full configure/build output for any rebuild. BUILD_INFORMATION.txt shipped by the owner contains the actual evaluated binary's configuration; compare against it. Do not promise a byte-identical historical rebuild from current latest image tags. Nor should changing a version string be presented as reproducing an original binary.

GPLv3 defines corresponding source to include the source and control scripts needed to generate/install/run/modify the work, with exceptions for System Libraries and generally available unmodified tools. A byte-identical rebuild is not a separate condition stated in the license. Historical environment capture is valuable for reproducibility; missing a general-purpose-tool version record is not, by itself, proof that a fresh FFmpeg build is legally required. Any actual missing required source/script remains an obligation to resolve.
Primary text: https://www.gnu.org/licenses/gpl-3.0.html (section 1).
